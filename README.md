# txrm-metadata-scraper

Python 2.7 application for extracting metadata from ZEISS Xradia `.txrm` files using the Xradia Python API.

## App

The application and its documentation are in:

```text
txrm_app/
```

See [`txrm_app/README.md`](txrm_app/README.md) for usage details.

## Install

See [`PYTHON27.txt`](PYTHON27.txt) for Python 2.7 and Xradia API setup instructions.

The required Xradia files are typically found under:

```text
C:\Program Files\Carl Zeiss X-ray Microscopy\Xradia Versa\
```
